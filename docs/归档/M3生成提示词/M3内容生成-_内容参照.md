## 3. 现有 tag 全集（**新增 tag 可以，但要克制**）

```
canned / food / dry / grain / drink / water / fresh / medkit / medicine
fuel / flammable / warmth / soft / power / tool / heavy / treat / luxury / keepsake
```

`tag` 的用途：玩家在整理期写"分区规则"时会引用它（"所有 canned 都放这块"）。
**所以 tag 是给玩家用来分类的，不是给你用来做笔记的** —— 同一个 tag 至少要有 3 件物资共用才有意义。

## 6. 四维与数值口径（写 `effect` 时参照）

### 6.1 四维（都是 0~100）

| 维 | 开局 | 含义 | 谁在扣它 |
| --- | --- | --- | --- |
| `health` 健康 | 100 | 归零 = 这局结束 | 生存期的缺货结算 |
| `mood` 心情 | 70 | 影响生存期的发挥 | 归位率低、缺货 |
| `stamina` 体力 | 100 | 每天行动都消耗 | 出门、整理、搬运 |
| `shelter` 庇护所 | 100 | 屋子的状态（漏风、结冰） | 灾难强度 |

**事件里四维的单次变动量：**

- 小：±2 ~ ±4（最常见，一条事件的正常幅度）
- 中：±5 ~ ±8（这条事件是当天的主要事件时才用）
- 大：±10 以上（**很少用**，留给"这一晚发生了大事"）

### 6.2 现金

- 两个身份开局：**900 元**（团购团长）/ **780 元**（加油站夜班员）
- 14 天刚需约 **700~810 元** —— 所以现金是**紧的**，事件里 ±50 已经是明显的大数
- 单条事件选项的现金变动区间：**-400 ~ +400**（超出会被校验判为离群值）

### 6.3 重量（`unitWeight`，kg/件）

参照现有物资的量级：

| 量级 | 例子 | 值 |
| --- | --- | --- |
| 极轻 | 绷带、电池 | 0.05 ~ 0.2 |
| 轻 | 罐头、泡面 | 0.3 ~ 0.5 |
| 中 | 矿泉水、牛奶 | 0.5 ~ 1.0 |
| 重 | 棉被、工具箱 | 2 ~ 4 |
| 很重 | 大米、面粉 | 5 ~ 8 |

**为什么重量重要**：玩家有「单趟手提上限」和「车载上限」两道闸门，
所以重量是**取舍的来源**。一箱水很重、一条烟很轻 —— 这个差别就是玩法。

## 8. 三张设计红线（引用数字前先读）

1. **只要"囤什么都行"成立，整理就失去意义。**
   所以**每个品类都必须在某一种灾难里是刚需** —— 你写的内容不要制造"某品类完全无用"的局面。
2. **代价都可逆、都能爬回来，但健康归零这一局就停在这里。**
   所以事件可以很疼，但**不要写"必死"的选项**。
3. **任何界面都得有一条"不参与"的路。**
   所以事件的选项里，永远要留一个"什么都不做/不去"的选择（它可以是纯休息）。
