## 六、要项目方知道的三件事

1. **事件的 `tags` 只有白天事件有**：`NightEventDef` 没有 `tags` 字段，入库脚本的白名单里也没有它 —— 所以夜间事件无法参与灾难的 `eventPoolWeights`。`night-02.json` 因此不写 tags（避免"写了不生效"）。
2. **`priorityCategories` 不可能场场唯一**：7 品类选 2~3 共 56 种组合，115 场必然复用（现有 44 种组合里 30 组被复用）。真正判换皮的仍是"任意两场是否只在前 4 维不同"，这一条已证明 0 对。
3. **维度 17 `specialMechanics` 一场都没写**（引擎未实现）。

## 七、没做的事

- **没有入库**：管道第 ⑥ 步"人工过一遍文案"在入库之前，留给项目方。命令：`node scripts/merge-content.mjs`，之后 `npm run check`。
- 社会族新增里的「失业潮」依赖策划案里尚未实现的收入结算；「治安真空 / 宵禁」用 `actionPointDelta` / `closedShopIds` / `npcVisitFactor` 表达，没有碰未实现的独有机制（各场 notes 里已注明）。
